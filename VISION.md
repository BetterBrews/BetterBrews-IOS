```

✓ CME futures prices
✓ NOAA weather data
✓ News RSS feeds
```

**Purpose:** Baseline context, free for everyone

### Layer 2: Community Data (Our Edge)


**How it works:**

- User-reported outcomes ("I sold here, in hindsight should have waited")
- Verified patterns (backtest accuracy: 73%)

**Transparency:**
- Always show WHY the AI recommends something
- Users can rate recommendations (feedback loop)
- Accuracy score shown: "82% accurate over last 90 days"

## The Technical Architecture (How It Must Be Built)

### Core Principles:

1. **Offline-First**: Works in field with no signal (Iowa farmland)
2. **Real-Time**: Data <5 minutes old during market hours
3. **Lightweight**: Entire app <50MB (rural internet)
4. **Fast**: Decision screen loads in <500ms
5. **Trustworthy**: All data sources cited, all AI explainable

### Stack (What's Actually Needed):

```swift
// MODELS (The Truth)
- Commodity: Price + Metadata + Sources
- Location: User location + nearby buyers
- Decision: Recommendation + Confidence + Evidence
- Pattern: Historical analysis + accuracy

// SERVICES (The Intelligence)
- PriceAggregator: Combine public + community data
- DecisionEngine: AI that recommends sell/wait/store
- PatternRecognizer: Detect historical patterns
- CommunityValidator: Verify user-reported data

// VIEWS (The Experience)
- DecisionView: "Sell today or wait?" (30-second answer)
- LocalBuyersView: "Who pays most near me?"
- PatternView: "What happened last time price did this?"
- CommunityView: "What are neighbors doing?"

// DATA SYNC
- Pull public data: Every 15 minutes
- Pull community data: Real-time (WebSocket)
- AI model updates: Weekly (on WiFi only)
- Offline mode: Last 7 days cached
```

### What We DON'T Need (Simplify Ruthlessly):

❌ Trade flow tracking (that's Kpler's $50k feature - not our focus)
❌ Forward curves (farmers don't trade derivatives)
❌ Vessel tracking (not relevant to farmers)
❌ 50 different commodities (start with corn/soybeans in Midwest)
❌ Six tabs (need ONE decision screen, not navigation maze)
